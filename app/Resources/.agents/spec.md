# Ramayana Storybook (v4): spec
A storytelling book in which every page fits the screen: illustration on the left, story on the right.

events (Khara and Dushana, Kumbhakarna, Meghnad, Ravana...), and a timeline map of the places Rama covered.
Pages: cover -> The Path of Rama (map) -> for each Kanda, an opener plus one page per key moment (33 in all).
v1-v3 are kept as earlier versions.
